🌐 Meu Portfólio Pessoal

Um espaço digital para apresentar meus projetos, habilidades e trajetória profissional como desenvolvedor.

📋 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal. O objetivo principal deste projeto é centralizar meus melhores trabalhos, destacar minhas principais competências técnicas e servir como um canal direto de contato para recrutadores, clientes e outros profissionais da área de tecnologia.

🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de desenvolvimento web:

Linguagens: HTML5, CSS3, JavaScript

Estilização / Frameworks: (Ex: Tailwind CSS / Bootstrap)

Ferramentas: Git e GitHub

✨ Funcionalidades

Apresentação Pessoal: Seção sobre minha trajetória, experiências e paixão por tecnologia.

Seção de Projetos: Exibição dos principais repositórios e aplicações desenvolvidas por mim, com links diretos.

Habilidades (Tech Stack): Lista das linguagens, frameworks e ferramentas que utilizo no dia a dia.

Contato: Links rápidos para minhas redes profissionais (LinkedIn, GitHub, e-mail).

⚙️ Como Executar o Projeto Localmente

Se você quiser rodar este projeto em sua máquina para explorá-lo:

Clone o repositório:

git clone https://github.com/LucasMiguel822/portifolio.git


Abra a pasta do projeto:

cd portifolio


Abra o arquivo principal:

Basta abrir o arquivo index.html diretamente no seu navegador favorito ou utilizar uma extensão como o Live Server no VS Code.
